# LinguaBloom full starter

This package contains a responsive multi-page educational website.

## Included
- Home
- Articles index
- Categories
- About
- Contact
- Privacy
- Four original starter articles
- Responsive CSS
- Mobile navigation
- robots.txt
- sitemap.xml
- SEO titles/descriptions/canonical placeholders

## Before launch
1. Replace `https://example.com/` with the real domain in canonical tags, robots.txt and sitemap.xml.
2. Connect the contact form and newsletter to services you have permission to use.
3. Add a real email/contact method.
4. Expand the article library with genuinely original, useful content.
5. Review the privacy policy for the actual services/cookies/ads you use.
6. Add Google AdSense only after the site is live, content-rich and approved.
7. Never click your own ads or ask visitors to click ads.

The starter intentionally contains no fake AdSense publisher ID or ad code.
